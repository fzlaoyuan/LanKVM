LanKVM 局域网键鼠共享 v1.2.0 —— macOS 安装说明
作者：老白玩AI   官网：https://laobaiai.com/

【安装】
1. 解压本安装包。
2. 右键点击“安装LanKVM.command”，选择“打开”，在弹出的提示中再点“打开”。
   （直接双击可能会提示“无法打开，因为它来自身份不明的开发者”——这是 macOS 对未签名脚本的默认拦截，
    用“右键 → 打开”即可。若仍被拦截：系统设置 → 隐私与安全性 → 页面下方点“仍要打开”。）
3. 按终端窗口里的提示操作。安装过程：
   - 已有合适的 Python（3.8 及以上，带 Tk 8.6）：直接使用，跳过安装；
   - 没有：自动使用安装包内置的 Python 3.12 免安装版（无需联网，只放在 LanKVM.app 内部）；
   - 生成“应用程序/LanKVM.app”（无写入权限时放在 ~/应用程序）。

【授权（必须）】
macOS 要求手动允许程序控制键盘鼠标：
  系统设置 → 隐私与安全性 → 辅助功能：打开 LanKVM
  系统设置 → 隐私与安全性 → 输入监控：打开 LanKVM
授权后退出并重新打开 LanKVM。首次运行若弹出“接受传入网络连接”，请选“允许”。

【Windows 和 Mac 混用】
- 用 Windows 的键盘控制 Mac：在 Mac（副机）上勾选“Ctrl 与 Cmd 互换”，
  这样 Windows 的 Ctrl+C / Ctrl+V 会变成 Mac 的 Cmd+C / Cmd+V。
- 文件复制粘贴：在访达里 Cmd+C 复制文件，到另一台电脑粘贴即可。
- 拖到屏幕边缘的蓝色投放区目前只支持 Windows；Mac 上请使用复制粘贴传文件。

【卸载】
双击“卸载LanKVM.command”（同样可能需要“右键 → 打开”）。

【说明】
本安装脚本尚未在真实 Mac 上完成测试；如遇问题，请截图终端窗口反馈。
